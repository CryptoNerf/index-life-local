Silhouette avatar library for the "My people" graph.

Drop stylish person-silhouette images here (PNG with transparent background
works best; SVG / WEBP / JPG also accepted). Each file becomes a pickable
avatar when adding or editing a person — shown as a face in the "crowd".

Naming: anything is fine; the filename is stored as the person's chosen avatar.
Recommended: square-ish images, ~256–512px, transparent background, one
silhouette per file. Suggested set: a variety of poses / body types so users
can find one that fits each person.

Examples:
  woman-standing.png
  man-walking.png
  person-sitting.png

No code changes needed — the picker lists whatever files are in this folder.
