# Модульная система

[← к оглавлению](../README.md) · [English](../en/modules.md)

Базовый дневник (календарь, записи, жизнь в неделях, аккаунт, синхронизация) работает сам по себе. Всё остальное — **опциональные модули**, которые ты включаешь по желанию.

| Модуль | Что добавляет | Зависимости |
|---|---|---|
| **Графики** | Визуализации настроения | нет (только активация) |
| **Кастомизация** | Цвета, шрифты, фон, мозаика | нет (только активация) |
| **AI-психолог** | Чат с локальной моделью | большие (LLM ~4.7 ГБ + Python-пакеты) |
| **Нейронная карта** | Карта тем дневника | средние (~50 МБ, нужен AI-психолог) |

---

## Как это устроено

Модули лежат в `app/modules/<имя>/` и **автоматически обнаруживаются** при старте. Модуль включается, только если выполнены его зависимости:

- **Лёгкие модули** (графики, кастомизация) не требуют пакетов — включаются файлом-маркером (`graphics_enabled`, `customization_enabled`) в каталоге данных.
- **Тяжёлые модули** (AI-психолог, нейронная карта) требуют Python-пакеты, которые ставятся в отдельное окружение `modules_venv/`.

Если папка модуля есть, но зависимости не установлены — приложение просто пропускает модуль и пишет об этом в лог.

Включение/установка — на странице **Модули** внутри приложения (кнопка «Установить») или скриптами `install_modules.bat` / `install_modules.sh`.

## Установка модулей

### Внутри приложения

<!-- SCREENSHOT: страница «Модули» с кнопками установки и прогрессом | ../images/modules-page.png -->
Открой страницу **Модули** → нажми «Установить» на нужном модуле. Прогресс отображается прямо в окне. После установки тяжёлого модуля нужен перезапуск приложения.

### Скриптами (из релиза / исходников)

**Windows:** двойной клик по `install_modules.bat` (или с аргументами):
```
install_modules.bat --module assistant --profile auto
```

**macOS (Apple Silicon, DMG):** двойной клик по `Install Modules.command` рядом с приложением — он всё сделает сам.

**macOS / Linux (из исходников):**
```
bash install_modules.sh --module assistant --profile auto
```

GGUF-модель AI-психолога (~4.7 ГБ) скачивается автоматически при установке.

## GPU-профили AI-психолога

AI-психолог может считать на CPU или на GPU. Профиль выбирается при установке:

| Профиль | GPU | Скорость | Требования |
|---|---|---|---|
| `auto` | Автодетект | Зависит | **Рекомендуется** — сам выбирает лучший вариант |
| `cpu` | Нет | ~3–5 ток/с | Любая система с 16 ГБ RAM |
| `vulkan` | Любой GPU | ~40–55 ток/с | GPU с поддержкой Vulkan (NVIDIA/AMD/Intel), 8 ГБ+ VRAM, SDK не нужен |
| `cuda` | NVIDIA | ~40–50 ток/с | NVIDIA 8 ГБ+ VRAM, драйвер 452.39+ |
| `metal` | Apple | ~15–25 ток/с | Mac с Apple Silicon, 16 ГБ+ единой памяти (8 ГБ недостаточно) |
| `vulkan-source` / `cuda-source` | — | — | Сборка из исходников (только если готовые не подошли) |

**Какой выбрать:**
- `auto` — в большинстве случаев. Определяет GPU и берёт готовую сборку, SDK ставить не нужно.
- `vulkan` — готовое колесо, работает на любом GPU.
- `cuda` — готовые CUDA 12.4 колёса для NVIDIA (нужен только современный драйвер).
- `metal` — для Apple Silicon.

> Готовые Vulkan-колёса берутся из GitHub-релиза приложения. Если переустанавливаешь релизы/теги — см. примечание в [AI-психолог → Системные требования](ai-psychologist.md#системные-требования).

### Требования NVIDIA
- **Драйвер:** 452.39+. Проверка: `nvidia-smi`.
- **VRAM:** минимум 8 ГБ.

## Сброс окружения модулей

Если установка сломалась или зависла, на странице **Модули** есть «Сбросить окружение модулей»: оно стирает `modules_venv/` и ставит заново. **Скачанные AI-модели сохраняются** — удаляются только Python-пакеты. После сброса переустанови нужные модули и перезапусти приложение.

---

## Python

Требуется Python 3.12 — он должен совпадать с интерпретатором в готовой сборке и в виртуальном окружении модулей (C-расширения вроде `llama_cpp` жёстко привязаны к минорной версии Python по ABI). В Windows установщик поставит Python 3.12 автоматически, если его нет.
